# Управляемый магазин — проверенный результат

Express 5 / SQLite / Sharp / Zod. Защищённый /admin: загрузка фото, товары, цены, остатки, черновики, публикация/снятие/архив. Заказы сохраняются на сервере, итог вычисляется по БД, остаток резервируется атомарно; администратор видит заказ, подтверждает/завершает/отменяет. Повтор запроса не создаёт второй заказ. Демо-товары не попадают в настоящие заказы. Утверждённый дизайн сохранён.

Проверки: production build; 11 Vitest-тестов; 12 API-сценариев + родительский тест (13 passed); 11 Chromium-проверок управляемого магазина; 16 holiday-world browser checks. Проверены загрузка реального PNG, черновик/публикация/снятие/архив, корзина/избранное/сравнение, заказ с серверной ценой, кабинет/отмена/остатки, перезапуск SQLite, гонки/идемпотентность и отклонение неавторизованных/CSRF/повреждённых/слишком больших запросов. 360/768/1024/1440 без горизонтального переполнения, browser runtime errors 0.

Все тестовые данные/логины находились только во временных изолированных БД и удалены. Настоящий каталог пуст. Скриншоты managed-store показывают явно тестовый товар, не реальное предложение. Пароли, токены, SQLite и фото владельца не вложены в архивы.

Сейчас только BOX: http://127.0.0.1:5174/ и /admin, API 127.0.0.1:5175. Защищённая настройка администратора владельцем: npm run setup:admin. Общего пароля нет; администратор намеренно не инициализирован. Публичного хостинга/домена/HTTPS/deployment-доступа не предоставлено. Онлайн-оплата, SMS/email, логистика и внешние маркетплейсы не подключены. НЕ опубликованный сервис для публичных продаж. Dockerfile/compose подготовлены, но Docker не запускался.

Инструкции: docs/MANAGED-STORE.md, docs/CATALOG.md, DEPLOYMENT-BLOCKER.md. Для сервера нужен production ZIP, не статический dist. Предыдущие исходники и архивы сохранены в /workspace/technoimperiya-before-managed-store.
