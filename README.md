# Техноимперия — новогодняя витрина телевизоров

Текущая версия: цельная чёрно-красная зимняя showroom-сцена с ёлкой, подарками, зимним окном и чёрной тумбой с красной кромкой. В ней стоит отдельный DOM-телевизор 16:9 с живой HTML-типографикой и настоящей motion-графикой. Старый вырезанный Santa/TV и dashboard не используются на главной.

## Запуск
```
npm install
npm run dev
npm run build
npm test
```
Сервер на BOX: http://127.0.0.1:5174/ — не публичная ссылка и не localhost компьютера пользователя. `dist/` — статическая сборка; для будущего размещения нужен SPA fallback.

## Что происходит в экране
Три сцены по 6 секунд: новогодний большой экран → демонстрация оформления скидки → выбор телевизора. Framer Motion 14.14.0: связанная смена композиции, раскрытие текста/числа, движение золотого украшения и ribbon path. Есть пауза/продолжение, прямой выбор кадра, next, остановка при keyboard-focus, уходе из viewport/вкладки; reduced-motion даёт статичное содержимое с ручным выбором кадров. Видео и звук не генерировались.

«30–70%» — явно подписанный пример графического оформления, НЕ действующая акция. Никаких действующих скидок или реальных цен не заявлено. Слово «наценкой» из старого постера удалено.

## Магазин сразу под сценой
Не декоративная кнопка: якорь ведёт прямо к полноценному встроенному каталогу с поиском, категориями, брендом, состоянием, ценой и сортировкой. Те же reusable компоненты работают на /catalog. Сохранены карточки, shared image transition в карточку, сравнение трёх моделей, избранное/корзина с persistence, количества/удаление/итоги и checkout-валидация. Внутренний каталог имеет отдельную светлую тёплую плоскость, а не ещё один пустой чёрный экран.

Реальный ассортимент пуст. Демо включается явно и подписано. Оплата, отправка, авторизация и backend не подключены; форма не создаёт заказ. Наполнение: docs/CATALOG.md. Реальные контакты/отзывы/наличие не придуманы.
