# Что мешает начать публичные продажи

1. Не предоставлен целевой хостинг/сервер с постоянным диском, доменом, HTTPS и доступом для deployment. Ни один найденный project config не задавал такой адрес. BOX localhost не публичен.
2. Владелец должен один раз безопасно задать пароль администратора через `npm run setup:admin` (вместо придуманного/переданного в чате пароля).
3. Загрузить реальные товары и подтверждённые контакты/условия магазина; онлайн-оплата и автоматическая доставка/уведомления не подключены.

Серверная реализация, кабинет, загрузка фото, публикация и приём/обработка заказов созданы. Инструкция: docs/MANAGED-STORE.md. Docker-сборка подготовлена, но не запускалась; Node-сборка и тесты проверяются локально.
