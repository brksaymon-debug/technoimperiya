# Аналитика: готовность подключения, без скрытого трекера
Никакие GA/Яндекс ID не предоставлены. Внешние аналитические скрипты, cookie-баннер с мнимым согласием и сетевые отправки не добавлены. Это отсутствие интеграции, а не работающая аналитика.

После предоставления владельцем оператора/политики, ID счётчика и выбранного механизма согласия подключается один адаптер со следующими событиями: view_item_list (режим real/demo, категория); select_item (ID товара); view_item; add_to_cart/remove_from_cart (ID, количество, цена); begin_checkout; purchase ТОЛЬКО после успешного /api/orders с серверным ID и итогом. Демо не должно отправлять purchase. Не передавать имя, телефон, email, адрес, пароль, сессионную cookie или полный URL с пользовательским поиском. Согласие должно предшествовать загрузке необязательного трекера. Ничего из этого не симулируется текущим предпросмотром.
