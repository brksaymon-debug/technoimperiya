# Загрузка реального товара

Текущий источник истины — SQLite на сервере, не `src/catalog.ts` и не localStorage.

1. Настройте администратора: `npm run setup:admin` в собственном терминале сервера.
2. Откройте `/admin` и войдите.
3. «Добавить товар»: название, бренд, категория, цена в рублях, количество, состояние, диагональ, описание, характеристики.
4. Загрузите JPEG/PNG/WebP. Первая фотография — обложка; её можно поменять.
5. Сохраните черновик либо отметьте «Опубликовать в каталоге». Для публикации требуется фото.
6. Откройте каталог/обновите страницу: товар доступен покупателю. Правки, снятие с публикации и архив работают из этого же кабинета.

Полные условия запуска, данных и защиты: [MANAGED-STORE.md](MANAGED-STORE.md). Массовый CSV/Excel-импорт не подключён. Старые статические `liveProducts` оставлены только как историческая совместимость: витрина их не читает. `demoProducts` используются только явно включённым демо-режимом и не являются предложением магазина. Настоящая скидка должна подтверждаться владельцем; текущая ТВ-реклама 30–70% помечена как иллюстрация.
