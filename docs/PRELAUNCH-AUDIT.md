# Предстартовый аудит: текущая интегрированная доработка

Дата: 21 ноября 2026, Asia/Shanghai (UTC+8). Это отчёт о проверенном исходнике и отдельной статической сборке, не заявление о развёрнутом серверном магазине и не сертификация качества.

## Критические ограничения запуска
- **Открыто / требуется владелец:** GitHub Pages обслуживает только предпросмотр. SQLite, загрузка товаров, закрытый администратор и приём заказов требуют Node 24.x сервера с постоянным приватным диском и HTTPS. В предпросмотре нет обращения к API, реального заказа, оплаты или имитации входа администратора.
- **Открыто / требуется владелец:** подтверждённые контакты/адрес/оператор, окончательная правовая политика, срок хранения/основание обработки, условия доставки/гарантии, реальные товары и цены не предоставлены. Не созданы вымышленные реквизиты, отзывы, карта, сотрудники, гарантии «2 часа» или пустые официальные блоки. /privacy прямо обозначает недостающие сведения.
- **Открыто / требуется владелец:** первая установка администратора выполняется владельцем в защищённом окружении по существующей инструкции. Пароли, сессии, личные SQLite и загруженные фотографии покупателей не включены в публикацию.

## Цена, ассортимент и честность рекламы
- Текущая цена задаётся администратором в рублях (до двух знаков); сервер пересчитывает строки и итог в целых копейках. Количество, остатки, версия и идемпотентность проверяются сервером. Манипуляция ценой и перепродажа сверх остатков отклоняются.
- Правила наценки, старая цена, доказательства скидки/бизнес-акции не предоставлены. Новые правила не придуманы. «30–70%» в оригинальном логотипе владельца не перерисовано; рекламный кадр ТВ явно демонстрационный, весь Pages обозначен как предпросмотр с непродающимися примерами.
- Тестовые товары/контакты/заказы создавались только во временной изолированной БД и удалены вместе с ней. Реальный каталог не заселялся.

## Что нельзя считать завершённым
Клиентский HashRouter-предпросмотр не является полноценной индексируемой SEO-публикацией: параметры отдельных hash-страниц видны после JS; серверный SSR/метаданные без JS не реализованы. На GitHub Pages project robots.txt не управляет robots в корне домена; meta noindex содержится и в исходном HTML. Онлайн-оплаты и внешнего маркетплейса нет. Контакты/юридические условия/отзывы/карта/реальный ассортимент/счётчик аналитики не выдуманы. Существующая конфигурация бэкапа БД/файлов описана в исходных инструкциях; рабочие приватные данные в upload/ZIP не включаются.

Последующий один responsive-проход: см. [MOBILE-PERFORMANCE.md](MOBILE-PERFORMANCE.md). Мобильный image payload уменьшен на81.4%; измеренный optimized LCP8.703с остаётся выше цели. Финальная геометрия проверена smoke, не новым LH.
