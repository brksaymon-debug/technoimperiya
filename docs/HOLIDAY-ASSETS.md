# Holiday environment provenance

Original coherent room environment generated specifically for this brief using the built-in image-generation tool, after the user explicitly requested a created atmospheric New Year visual. It is campaign artwork, NOT a photograph of a real company showroom or real product stock.

Original: original-art/holiday-environment-original.jpg (1280×720).
Web delivery: public/art/holiday-environment.webp (1280×720, 111900 bytes).
Scene brief: continuous burgundy winter showroom with snowy window at far left, evergreen/gold ornaments/gifts at far right, clear champagne-gold plinth and room to place a coded television; physical warm/cool lighting, no lettering, people, TV, UI or logos baked into the image. One image generated, no repeated alternatives. Code places the actual 16:9 TV, text, controls, ribbon, ornament and campaign graphics independently above this environment.

Existing authorized screen-landscape.webp reused only within the first TV story, not as the whole website's background. Original Santa/reference assets preserved in source but not used in active homepage.

Image prompt preparation used visual-image guidance by Serge Shima, https://github.com/smixs/visual-skills (CC BY 4.0; https://sergeshima.com). The generation tool does not expose model selection; no claim is made about which underlying image model produced the asset.
